# thefixer.in

Landing page for The Fixer.

Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4. The hero is a particle system rendered on a canvas via Three.js with a WebGPU path and WebGL2 fallback. Animations use GSAP and Motion; smooth scrolling uses Lenis.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm start` — run the production build
- `npm run lint` — ESLint
- `npm test` — Vitest
